* Curriculum vitae

Bilingual (EN/NL) curriculum vitae rendered with [[https://typst.app][Typst]]
using the [[https://typst.app/universe/package/brilliant-cv][brilliant-cv]]
package. No LaTeX, Pandoc or Make required.

** Requirements

- Typst (>= 0.14)
- The bundled fonts in =fonts/= (Font Awesome 7, Source Sans 3, Roboto)

** Layout

- Entry point: =cv.typ=
- Content per language: =profile_en/= and =profile_nl/= (one =metadata.toml=
  plus a =.typ= module per section: experience, education, technologies,
  hobbies, languages)
- Photo: =assets/photo.png=

To add a language, copy a =profile_<code>/= directory and translate it.

** Usage

#+BEGIN_SRC sh
  typst compile --font-path fonts cv.typ --input profile=en CV-Michael.Fatjanov-en.pdf
  typst compile --font-path fonts cv.typ --input profile=nl CV-Michael-Fatjanov-nl.pdf
#+END_SRC

Live preview while editing:

#+BEGIN_SRC sh
  typst watch --font-path fonts cv.typ --input profile=en
#+END_SRC
